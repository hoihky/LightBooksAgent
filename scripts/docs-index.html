LightBooksAgent

A local-first, multi-agent platform for publishing technical articles about programming, game development, and game design. Orchestrated with the Microsoft Agent Framework, a Blazor Server UI, human-in-the-loop gates, and llama.cpp for fully local LLM inference.

Highlights

Human topic first

Authors propose and confirm topics before agents research, outline, and write.

MAF workflows

Sequential orchestration with RequestPort HITL gates and JSON checkpoint resume.

Local LLM

OpenAI-compatible client pointed at llama.cpp — no cloud AI APIs required.

Agent memory

Episodic, semantic, and procedural memory distilled from feedback across articles.

Blazor monitoring

Dashboard, review queues, agent activity feed, and workflow controls.

MDWeb export

Optional Markdown and HTML publishing through the MDWeb static site generator.

Quick start

dotnet build
dotnet run --project src/LightBooksAgent.Web

Configure LocalLlm.BaseUrl in appsettings.json and ensure llama.cpp is listening on the configured port. Confirm a topic in the UI, then start the publishing workflow — it pauses at each human review gate until you approve.

Regenerate HTML docs

After editing Markdown under docs-src/, run ./scripts/generate-docs.sh from the repository root to rebuild the HTML pages in docs/.
